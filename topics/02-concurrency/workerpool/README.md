# Код к ролику "Worker Pool в Go: задача с собеса от галер до бигтеха"

📺 Видео-разбор (откуда взяты исходники): https://www.youtube.com/watch?v=OHCqbREDx8U

Три уровня глубины одной и той же задачи - как её решат junior / middle / senior на собеседовании.

## Структура

```
код/
├── junior/   # 🔻 Базовый воркерпул (~40 LOC). Уровень галеры/аутсорса (150К).
├── middle/   # 🟡 Production-ready: context, recover, single-producer (≈80–120 LOC). [TODO]
└── senior/   # 🔥 Backpressure + observability + dynamic resize. [TODO]
```

Каждая папка - самостоятельный Go-модуль, чтобы открывать и записывать на видео независимо.

## Запуск

```bash
cd код/junior
go run .
```

## Что не так с junior-версией (для разбора в ролике)

- **Race на `closed`:** между `mu.Unlock()` и `p.tasks <- f` канал могут закрыть → паника `send on closed channel`.
- **Нет panic recovery:** упавшая таска убивает воркер → деградация пула.
- **Нет контекста:** грациозного шатдауна нет, висим до конца всех тасок.
- **Магическое число 100:** размер буфера хардкодом.
- **Mutex + канал:** классический code smell, на собесе сразу спрашивают "зачем?".
