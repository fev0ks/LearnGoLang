# Интеграция с LLM API

Как устроен вызов языковой модели с точки зрения backend-сервиса: из чего состоит запрос, чем отличаются провайдеры, как получить предсказуемый ответ и откуда берётся время ответа.

Раздел не про обучение моделей. Он про работу с готовым HTTP API из своего сервиса.

## Материалы

- [01. Анатомия LLM API](./01-llm-api-anatomy.md) — что уходит на сервер провайдера и что приходит обратно; сравнение OpenAI, Anthropic и Google; где протекает попытка сделать общую абстракцию
- [02. Структурированный вывод](./02-structured-outputs.md) — как получить от модели объект по схеме, а не текст, который надо парсить
- [03. Рассуждающие модели и латентность](./03-reasoning-and-latency.md) — из чего складывается время ответа, почему вызов идёт пятнадцать секунд и что с этим делать

Примеры кода вынесены в [examples/](./examples/).

---

## Что нужно понимать

- вызов модели — обычный HTTP-запрос без состояния на стороне сервера;
- время ответа определяется объёмом вывода, а не объёмом ввода;
- предсказуемость формата обеспечивается схемой в запросе, а не просьбой в тексте;
- у каждого провайдера свой формат запроса, и общая обёртка над ними протекает.
