# Примеры: вызов инструментов, агентный цикл и навыки

Минимальная эталонная реализация протокола вызова инструментов, цикла агента и реестра навыков. Код учебный: типы упрощены, сетевой транспорт вынесен за интерфейс `Model`, реального клиента к провайдеру здесь нет.

## Файлы

- [tool_calling.go](./tool_calling.go) — типы протокола и `RoundTrip`: один полный обмен «объявить → заявка → выполнить → вернуть». Разбор в [02-tool-calling.md](../02-tool-calling.md).
- [agent_loop.go](./agent_loop.go) — `Run`: тот же обмен в цикле с ограничителями по итерациям и бюджету токенов. Разбор в [03-agent-loop.md](../03-agent-loop.md).
- [skills.go](./skills.go) — `Catalog`: реестр навыков с постепенным раскрытием, инструмент `load_skill` и проверка пути. Разбор в [06-skills.md](../06-skills.md).

## На что смотреть в коде

- `ToolCall.ID` связывает заявку с результатом — без него параллельные вызовы не сопоставить;
- `Registry.execute` всегда возвращает результат, в том числе для неизвестного инструмента и для ошибки: выброшенный результат оставляет модель в ожидании;
- `executeAll` собирает все результаты в одно сообщение, а не в несколько;
- сообщение ассистента с заявками кладётся в историю вместе с результатами;
- в `Run` вся история уходит заново на каждой итерации — отсюда квадратичный рост стоимости;
- проверка `StopMaxTokens` ловит оборванный ответ, который приходит с успешным статусом;
- в `Catalog.names` имена отсортированы: перестановка строк меняет байты начала запроса и обнуляет кэш промпта;
- `Catalog.ReadFile` проверяет путь после `filepath.Clean`: аргумент приходит от модели и является недоверенным вводом.
