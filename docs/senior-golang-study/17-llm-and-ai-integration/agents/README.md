## Что нужно понимать

- модель не вызывает функции — она просит их вызвать, а выполняет их сервис;
- агент — система, которой задают цель, а не последовательность шагов; технически это цикл вокруг вызова инструментов с условием остановки, а не отдельная технология;
- циклом владеет код: список инструментов, проверка аргументов, авторизация и счётчик шагов лежат в приложении;
- каждая итерация агента увеличивает контекст, поэтому стоимость растёт быстрее числа шагов;
- если последовательность шагов известна заранее, это пайплайн, и агент здесь избыточен;
- несколько агентов заводят ради контекста и параллельности, а не ради «ума»: исполнитель читает много, возвращает мало;
- MCP стандартизует подключение инструментов, но не избавляет от их проектирования;
- навык хранит процедуру вне постоянного контекста: в каждом запросе висит только описание.
