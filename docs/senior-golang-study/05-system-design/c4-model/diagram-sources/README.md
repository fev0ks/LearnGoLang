# Исходники C4-диаграмм

Mermaid-исходники изображений из [C4-раздела](../README.md):

- [00-c4-zoom.mmd](./00-c4-zoom.mmd) — уровни приближения;
- [01-system-context.mmd](./01-system-context.mmd) — System Context;
- [02a-container-subscriptions-and-matching.mmd](./02a-container-subscriptions-and-matching.mmd) — Container view подписок и сопоставления;
- [02b-container-delivery.mmd](./02b-container-delivery.mmd) — Container view доставки;
- [03-component.mmd](./03-component.mmd) — Component diagram Matcher;
- [04-dynamic.mmd](./04-dynamic.mmd) — обработка одного изменения цены;
- [05-deployment.mmd](./05-deployment.mmd) — production deployment по зонам.

После изменения исходника нужно перегенерировать соответствующий PNG в
`../assets/` и проверить его в ширине Markdown-статьи. Синтаксически успешный
рендер не гарантирует, что подписи читаются и стрелки не пересекаются.
