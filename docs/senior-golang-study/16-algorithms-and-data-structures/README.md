## Что важно уметь

- Объяснить O(1), O(log n), O(n), O(n log n), O(n²) и назвать пример на каждый класс.
- Заметить O(n²) там, где хватит O(n) с хеш-таблицей, — самая частая ошибка на практике.
- Написать два указателя, скользящее окно и бинарный поиск без подсказок, не путаясь в границах.
- Обойти дерево итеративно: в ширину через очередь, в глубину через стек.
- Применить шаблон перебора с возвратом и объяснить, что именно отсекается.
- Использовать `container/heap` для top-K вместо полной сортировки.
- Объяснить разницу мемоизации и табуляции и назвать, когда какой вариант уместнее.
- Назвать сложность стандартных операций Go: `append`, поиск в map, `slices.Sort`.
