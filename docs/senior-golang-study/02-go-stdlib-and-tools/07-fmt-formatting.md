## Семейство функций: Print / Sprintf / Fprintf

Имя функции = префикс (**куда**) + есть ли `f`/`ln` (**как**):

| Куда | Без формата | С форматом (`...f`) | С переводом строки (`...ln`) |
|---|---|---|---|
| в stdout | `Print` | `Printf` | `Println` |
| в строку | `Sprint` | `Sprintf` | `Sprintln` |
| в `io.Writer` | `Fprint` | `Fprintf` | `Fprintln` |
| в `error` | — | `Errorf` | — |

```go
s := fmt.Sprintf("%s=%d", k, v)        // собрать строку
fmt.Fprintf(w, "%s\n", line)           // писать в io.Writer (http.ResponseWriter, файл, Builder)
err := fmt.Errorf("open %s: %w", p, e) // ошибка с обёрткой (см. ниже)
```

Различия `Print`/`Println`: `Print` ставит пробелы только между **не-строковыми** операндами; `Println` — всегда пробелы и `\n` в конце. На практике для логов/сообщений берут `Printf`/`Sprintf` — предсказуемее.

## Универсальные глаголы: `%v` `%+v` `%#v` `%T`

Работают с **любым** типом — основной инструмент для отладки.

```go
type Point struct{ X, Y int }
p := Point{1, 2}
```

| Глагол | Что показывает | Вывод для `p` |
|---|---|---|
| `%v` | значение «по умолчанию» | `{1 2}` |
| `%+v` | значение **с именами полей** | `{X:1 Y:2}` |
| `%#v` | Go-синтаксис (как написал бы в коде) | `main.Point{X:1, Y:2}` |
| `%T` | тип значения | `main.Point` |

Указатель на структуру `%v`/`%+v` показывают со знаком `&`:

```go
fmt.Printf("%v\n", &p)   // &{1 2}
fmt.Printf("%+v\n", &p)  // &{X:1 Y:2}
```

Правило выбора:
- **`%+v`** — дефолт для логов и отладки структур (видно, какое поле какое);
- **`%#v`** — когда нужен валидный Go-литерал (тесты, генерация, точный дамп с типами);
- **`%v`** — компактно, когда поля и так понятны;
- **`%T`** — когда важен именно тип (отладка `any`, type switch).

Карты `fmt` печатает с **сортировкой по ключу** (детерминированно):

```go
fmt.Printf("%v\n", map[string]int{"b": 2, "a": 1}) // map[a:1 b:2]
```

## Глаголы по типам

**Строки и байты:**

| Глагол | Делает | Пример (`s="Go"`) |
|---|---|---|
| `%s` | строка как есть | `Go` |
| `%q` | строка в кавычках, с экранированием | `"Go"` |
| `%x` / `%X` | hex-байты | `476f` / `476F` |
| `% x` | hex с пробелами между байтами | `47 6f` |

```go
b := []byte("Hi")
fmt.Printf("%s %v\n", b, b)  // Hi [72 105]  — %s декодирует байты, %v показывает числа
```

**Целые числа:**

| Глагол | Система | `255` → |
|---|---|---|
| `%d` | десятичная | `255` |
| `%b` | двоичная | `11111111` |
| `%o` | восьмеричная | `377` |
| `%x` / `%X` | hex | `ff` / `FF` |
| `%#x` | hex с префиксом | `0xff` |
| `%c` | символ по code point | `ÿ` |
| `%q` | символ в кавычках | `'ÿ'` |
| `%U` | Unicode-нотация | `U+00FF` |

```go
fmt.Printf("%d %c %q %U\n", 'A', 'A', 'A', 'A') // 65 A 'A' U+0041
```

**Числа с плавающей точкой:**

| Глагол | Формат | `3.14159` → |
|---|---|---|
| `%f` | без экспоненты | `3.141590` |
| `%.2f` | 2 знака после точки | `3.14` |
| `%e` / `%E` | экспоненциальная | `3.141590e+00` |
| `%g` | компактная (`%e` или `%f` по ситуации) | `3.14159` |

**Прочее:**

| Глагол | Для чего | Пример |
|---|---|---|
| `%t` | bool | `true` |
| `%p` | адрес указателя | `0x43f68d38e020` |
| `%T` | тип | `int`, `*main.Point` |
| `%%` | литеральный знак `%` | `%` |

## Флаги: ширина, точность, выравнивание

Синтаксис глагола: `%[флаги][ширина][.точность]глагол`.

```go
fmt.Printf("%5d|%-5d|%05d\n", 42, 42, 42)   // "   42|42   |00042"
fmt.Printf("%8.2f\n", 3.14159)               // "    3.14"  (ширина 8, 2 знака)
fmt.Printf("%-10s|\n", "hi")                 // "hi        |" (выравнивание влево)
```

- **ширина** — минимальное число символов (добивает пробелами);
- **`.точность`** — для float число знаков после точки; для строки — обрезка до N символов; для `%d` — минимум цифр;
- **`-`** — выравнивание влево;
- **`0`** — добивать нулями (числа);
- **`+`** — всегда печатать знак (`+42`);
- **пробел** — пробел вместо `+` для положительных;
- **`#`** — «альтернативный» формат (`0x` для hex, Go-синтаксис для `%#v`).

Удобно: `*` берёт ширину/точность из аргумента — `fmt.Printf("%.*f", 2, x)` (точность = 2 из аргумента).

## Интерфейсы: Stringer, Formatter, GoStringer

`fmt` спрашивает у значения, как себя печатать, через интерфейсы — это позволяет задать своё представление.

```go
// Stringer — используется для %v и %s
type Stringer interface{ String() string }

type Color int
func (c Color) String() string { return [...]string{"red", "green", "blue"}[c] }

fmt.Printf("%v %s\n", Color(2), Color(0)) // blue red
```

| Интерфейс | Метод | Когда вызывается |
|---|---|---|
| `fmt.Stringer` | `String() string` | для `%v`, `%s` (и других строковых) |
| `error` | `Error() string` | для `%v`, `%s`, если тип — ошибка |
| `fmt.GoStringer` | `GoString() string` | для `%#v` |
| `fmt.Formatter` | `Format(f State, verb rune)` | полный контроль над **всеми** глаголами |

`%#v` не вызывает `String()` — он показывает структуру/Go-синтаксис. Это важно: если в логе нужен «человеческий» вид — `%v`/`%s`, если сырой — `%#v`.

⚠️ **Бесконечная рекурсия в `String()`:** если внутри `String()`/`Error()` напечатать сам ресивер через `%v`/`%s`, `fmt` снова позовёт `String()` → переполнение стека:

```go
func (c Color) String() string {
    return fmt.Sprintf("%v", c) // ⚠️ infinite recursion → stack overflow
}
```

Лечение: приводи к базовому типу — `fmt.Sprintf("%d", int(c))`.

## Ошибки форматирования и `%w`

`%w` — особый глагол **только для `fmt.Errorf`**: оборачивает ошибку, сохраняя цепочку для `errors.Is`/`As`.

```go
err := fmt.Errorf("load config: %w", io.EOF)
errors.Is(err, io.EOF) // true — связь сохранена
```

`%v` для ошибки лишь подставит текст, **связь потеряется** (`errors.Is` вернёт `false`). Подробно про `%w` vs `%v`, несколько `%w`, кастомные `Error()` — в [01-go-core/05-error-handling](../01-go-core/05-error-handling.md#оборачивание-с-контекстом-правила-w).

## Частые ошибки

Когда глагол не подходит типу, `fmt` **не паникует**, а печатает диагностику прямо в вывод:

```go
fmt.Printf("%d %s\n", "str", 42) // %!d(string=str) %!s(int=42)
```

- **`%!verb(type=value)`** — глагол не совпал с типом. `%!d(string=...)` = ждали число, дали строку.
- **`%!(EXTRA ...)`** — аргументов больше, чем глаголов.
- **`%!(MISSING)`** — аргументов меньше, чем глаголов.

Другие распространённые:
- **`%v` от `[]byte`** даёт числа (`[72 105]`), а не текст — для текста нужен `%s`.
- **`%d` от `rune`/`byte`** печатает **число** (code point), не символ — символ это `%c`.
- **`%s` от структуры без `String()`** напечатает `{...}` — для имён полей удобнее `%+v`.
- **`%p` vs `%v` для указателя**: `%p` — адрес, `%v` — `&{значение}`.
- **Забытый `\n`**: `Printf` не добавляет перевод строки (в отличие от `Println`).
- **`go vet`** ловит несовпадение глаголов и аргументов на этапе проверки — не игнорируй его предупреждения про `fmt`.

## Interview-ready answer

**1. Чем отличаются `%v`, `%+v`, `%#v`?**

- `%v` — значение по умолчанию (`{1 2}`); `%+v` — с именами полей (`{X:1 Y:2}`), дефолт для логов; `%#v` — валидный Go-синтаксис с типом (`main.Point{X:1, Y:2}`). `%#v` не вызывает `String()`, остальные — вызывают.

**2. Как `fmt` узнаёт, что печатать для `%v`/`%s`?**

- Если тип реализует `fmt.Stringer` (`String() string`) или `error` (`Error() string`) — зовёт его. Для полного контроля есть `fmt.Formatter`. Для `%#v` — `GoStringer`.

**3. Чем `%w` отличается от `%v` в ошибках?**

- `%w` (только в `Errorf`) оборачивает ошибку, сохраняя цепочку → `errors.Is/As` работают. `%v` лишь вставляет текст, связь теряется.

**4. Что выведет `%d` для строки?**

- `%!d(string=...)` — `fmt` не паникует, а печатает диагностику о несовпадении глагола и типа. `go vet` ловит это статически.

**5. Как напечатать `[]byte` как текст?**

- `%s` (декодирует байты в строку). `%v` покажет числа `[72 105]`.

**6. Как сделать ширину/точность из переменной?**

- Через `*`: `fmt.Printf("%*.*f", width, prec, x)` — берёт ширину и точность из аргументов.
