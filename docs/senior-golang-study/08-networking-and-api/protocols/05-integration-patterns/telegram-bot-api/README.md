# Telegram Bot API

Бот в Telegram — это обычный HTTP-клиент к чужому API плюс приёмник входящих событий. Отдельная папка нужна потому, что на нём одновременно сходятся все три интеграционных паттерна из родительского раздела: доставка апдейтов идёт с повторами, повтор надо гасить идемпотентностью, а отправка ограничена лимитами на стороне Telegram.

Раздел не про конкретную библиотеку-обёртку. Он про механику самого API и про то, какие решения приходится принимать при написании бота, который переживает перезапуск, дубли и лимиты.

## Порядок чтения

Первые три материала образуют связку и читаются подряд: приём порождает повторы, повторы гасятся дедупликацией, отправка ограничена лимитами. Дальше порядок свободный — 04 и 05 про интерфейс диалога, 06 про файлы, 07 про поведение при отказах, 08 про частный, но показательный случай долгого ответа.

Версии и числа проверены по [Telegram Bot API](https://core.telegram.org/bots/api) и [Bot FAQ](https://core.telegram.org/bots/faq) в августе 2026 года, на Bot API 10.2. Лимиты отправки живут в FAQ и сформулированы как рекомендации — перед тем как закладывать их в расчёты, стоит сверяться заново.
