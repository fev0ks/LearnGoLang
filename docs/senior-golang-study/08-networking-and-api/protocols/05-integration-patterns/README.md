# Интеграционные паттерны

В отличие от остальных папок каталога, здесь нет ни одного протокола. Это приёмы, которые реализуются любым транспортом — по HTTP, по gRPC, через брокер — и нужны ровно потому, что сеть ненадёжна: доставка бывает повторной, потребитель бывает медленнее отправителя, а обработать одно и то же событие дважды нельзя.

Три материала образуют связку: webhooks порождают повторные доставки, идемпотентность делает повтор безопасным, ограничение частоты защищает от потока повторов.
