# Стили API и контракты

Транспорт доставляет байты, но ничего не говорит о том, что они значат. Материалы этой папки — про договорённости поверх транспорта: как адресовать операции, как описать контракт, чтобы по нему генерировался код, и как сообщать об ошибке.

Собственного формата на проводе почти ни у кого здесь нет: REST — ограничения поверх HTTP, gRPC — соглашение поверх HTTP/2, GraphQL — язык запросов плюс договорённость возить его по HTTP, OpenAPI — вообще только язык описания. Исключение — SOAP со своим конвертом. Подробнее о классификации — в [README каталога](../README.md).
