# HTTP

Сам протокол и его реализация в Go. Здесь три материала: устройство версий протокола и две стороны работы с ним — сервер, который принимает запросы, и клиент, который ходит наружу.

Разделение на «протокол» и «Go» намеренно не сделано: параметры `http.Server` и `Transport` без понимания кадров, потоков и повторного использования соединений превращаются в набор магических чисел.
