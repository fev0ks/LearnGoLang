# Транспорт

Уровень, на котором стоит всё остальное в каталоге: HTTP всех версий кроме третьей, gRPC, WebSocket, SSE, соединения с базами и брокерами. Половина «необъяснимого» поведения прикладного уровня объясняется именно здесь — почему первый запрос по новому соединению медленнее следующих, почему широкий канал не даёт ожидаемой скорости, почему данные приходят рывками.
