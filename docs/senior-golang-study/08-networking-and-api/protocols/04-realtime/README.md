# Реалтайм

Общее у материалов папки — соединение живёт дольше одного запроса, и это меняет всё: балансировщик не может переложить трафик на другую реплику по ходу дела, деплой рвёт соединения клиентов, а состояние подписок приходится где-то держать.

Папка собрана по задаче, а не по классу сущности: WebSocket и WebRTC — полноценные протоколы, SSE — всего лишь формат тела обычного HTTP-ответа, который сервер не закрывает. Выбирают между ними обычно вместе, поэтому и лежат рядом.
