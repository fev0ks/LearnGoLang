# Подборки вопросов к собеседованиям

Здесь собраны списки вопросов для подготовки к Go/backend-собеседованиям. Материалы различаются по охвату: от короткого топ-50 до больших тематических банков, восстановленных прогонов отдельных собеседований и вопросов для обратного интервью.

## Как читать

1. Начать с топ-50, чтобы быстро проверить базовые темы.
2. Пройти сводный банк и закрыть пробелы по ссылкам на профильные материалы.
3. Выбрать один-два прогона, близких к уровню и формату предстоящего собеседования.
4. Перед финальными этапами подготовить вопросы компании и примеры из собственного опыта.
